# One Word From Your Ex

Entry for the [make.fun bounty](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2): exactly one word, the word my ex would use to describe me.

The word: **roommate**.

By the end, that was all I was. Not a villain, not a mistake — just the person sharing the flat, splitting the bills, sleeping on opposite sides of a bed that used to mean something. It is funny because it is bleak, and it stings because it is true.

## How it works

`main.ts` (Node 22, standard library only) writes the single word to `/output/entry.txt`, validating the gate first: 1 to 24 characters, exactly one word, no whitespace. It then reads the file back and checks the content matches, so the shipped text is exactly the word.

Run it with:

```sh
node main.ts
```
